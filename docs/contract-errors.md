# Contract Error Codes

This document is generated from the `ContractError` enum in the smart contract source.
Do not edit this file by hand. Regenerate it with:

```sh
node scripts/generate-contract-errors.mjs
```

CI runs the same generator and fails if the committed table drifts from the enum.

| Code | Variant | Description |
| --- | --- | --- |
| 1 | `Unauthorized` | Caller is not authorized to perform the requested action. |
| 2 | `NotInitialized` | The contract has not been initialized yet. |
| 3 | `AlreadyInitialized` | The contract has already been initialized. |
| 4 | `InvalidInput` | One or more supplied arguments are invalid. |
| 5 | `InsufficientFunds` | The account does not hold enough funds for the operation. |
| 6 | `NotFound` | The requested resource does not exist. |
| 7 | `AlreadyExists` | The resource already exists and cannot be created again. |
| 8 | `Overflow` | An arithmetic operation overflowed. |
| 9 | `Underflow` | An arithmetic operation underflowed. |
| 10 | `Paused` | The contract is paused and cannot process the request. |
| 11 | `MaxBeneficiariesExceeded` | The configured maximum number of beneficiaries has been exceeded. |
| 12 | `InvalidBeneficiary` | A beneficiary entry is invalid. |
| 13 | `InvalidPercentage` | Beneficiary percentages are invalid or do not sum to 100. |
| 14 | `TransferFailed` | A token or value transfer failed. |
| 15 | `NotSupported` | The requested operation is not supported. |
